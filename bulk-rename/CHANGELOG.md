# Bulk Rename Changelog

## [Initial Version] - 2026-10-31

- Rename the files and folders selected in File Explorer or Finder with a live preview
- Search text or regular expressions, first or every match, name / extension / both
- Numbering with `${start=,increment=,padding=}`, date tokens, random strings
- lowercase, UPPERCASE, Title Case, Capitalize Each Word
- Conflicts and invalid names are skipped, swaps work, undo of the last rename
